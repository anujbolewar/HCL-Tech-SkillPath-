### Slide 2: The Problem — Curriculum Fragmentation & Drop-off
- **The Challenge**: Millions of online courses exist, but 90%+ of self-directed learners drop out.
- **Why?**:
  1. *Decision Fatigue*: Learners don't know what order to take courses in.
  2. *Hidden Prerequisites*: Jumping into complex topics without foundations causes frustration.
  3. *Static, One-Size-Fits-All Models*: Recommenders suggest single courses, not personalized roadmaps.
  4. *Black-Box Suggestions*: Learners aren't told *why* a module is necessary.

---

### Slide 3: The Vision — PathFinder AI
- An intelligent learning companion that transforms **any natural language goal** (careers, instruments, foreign languages, fitness, exams) into an interactive, prerequisite-aware **Directed Acyclic Graph (DAG)** roadmap.
- Paces milestones according to the learner's actual weekly time budget.
- Explains the pedagogical rationale behind every milestone with Explainable AI.

---

### Slide 4: The 6-Pillar System Architecture
1. **Pillar 1: Goal Intake** — Free-form prompt intake + 1-click domain quick picks.
2. **Pillar 2: Learner Profiling Engine** — Experience level, weekly hours, mastered skill inventory, learning style.
3. **Pillar 3: Recommendation Engine** — Curated courses, practice drills, and portfolio capstones from top global institutions.
4. **Pillar 4: DAG Flow Visualizer** — Interactive 2D React Flow canvas with zoom, pan, and prerequisite animations.
5. **Pillar 5: Explainable AI & Mentor** — 3-factor transparent scoring ledger + word-by-word streaming AI Mentor.
6. **Pillar 6: Visual Dashboard & Analytics** — Plotly Polar Radar Chart + adaptive milestone re-routing.

---

### Slide 5: Deep Tech & AI/ML Architecture
- **Multi-Model LLM Routing**:
  - Groq Cloud (Llama 3.3 70B & Llama 3.1 8B) for ultra-low latency inference.
  - Google Gemini (Gemini 2.5 Flash / Pro) for advanced reasoning.
  - Smart Offline Knowledge Base for zero-dependency instant execution.
- **Topological Invariant Enforcement**:
  - Kahn's algorithm validates acyclicity ($G=(V,E)$ is a strict DAG, $\text{cycles} = 0$).
- **Deterministic XAI Scorer**:
  - Transparent formula: $\text{Score} = \text{SkillGap}(40\%) + \text{PrereqReadiness}(30\%) + \text{ExperienceFit}(30\%)$.
